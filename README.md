## 🚀 Nasıl Kullanılır?

Bu repodaki dosyaları bilgisayarınıza indirip (clone) Podman ortamında çalıştırabilirsiniz.

Her proje klasörü:

* Podman container yapılarını
* `Containerfile` (Dockerfile eşdeğeri) tariflerini
* Podman Compose (`docker-compose.yml`) yapılandırmalarını içerir

İlgili proje dizinine girerek terminal üzerinden uygulamaları kolayca ayağa kaldırabilirsiniz:

```bash
podman-compose up
```

Ayrıca örnekler üzerinden:

* İki container arası iletişim (ping)
* Özel imaj oluşturma
* Pod yapısı kullanımı

Gibi konuları pratik edebilirsiniz.
